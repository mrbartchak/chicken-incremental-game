# Changelog

All notable changes to this project will be documented in this file.
## [v0.3.0] - 2026-02-09

### Added
- Silver chickens!
- Silver chickens will drop silver wings (higher base value)
- Upgrade track to increase silver chicken spawn rate

### Changed
- Chickens now spawn on floating island
- Reduce the spawn/game area size
- Spawner and Drops are now resource driven

### Fixed
- Chicken state management
- Some bugs with nodes not reading loaded state

## [v0.2.2] - 2026-02-08

### Added
- save/load game (also delete)

## [v0.2.1] - 2026-02-06

### Fixed
- Reworked the GameManager logic
- Split into a read only GameState RefCounted Object and a GameManager Autoload

## [v0.2.0] - 2026-02-05

### Added
- Shop menu
- 4 Upgrade tracks (spawn rate, max population, wing value, and attack speed)
- floating point numbers

### Changed
- Sound effects
- UI tweens

### Fixed
- Upgrades updating game state

## [v0.1.0] - 2026-01-27

### Added
- Initial release
- Chicken spawning
- Wing collection
